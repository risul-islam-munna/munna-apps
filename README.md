# Munna Apps — apps.munna.dev

Bilingual (English / বাংলা) static marketing, guide and legal site for **apps.munna.dev**.
The pages are generated by a tiny dependency-free Node script into plain HTML at the
repository root, so the site stays fully static and GitHub Pages can serve the branch as-is.
No backend, no database, no runtime translation, and no web version of any app.

## Routes and language rules

| Page | English | বাংলা |
|---|---|---|
| Hub | **`/`** (default) | `/bn/` |
| Bahon Boi landing | `/bahon-boi/en/` | **`/bahon-boi/`** (default) |
| Guide index / topics | `/bahon-boi/en/guide/`, `/bahon-boi/en/guide/<topic>/` | `/bahon-boi/guide/`, `/bahon-boi/guide/<topic>/` |
| Contact / Terms / Privacy | `/bahon-boi/en/{contact,terms,privacy}/` | `/bahon-boi/{contact,terms,privacy}/` |
| 404 | `/404.html` (both languages on one page — GitHub Pages serves one 404) | |

- Every URL renders exactly its own language. Browser language and saved preferences never redirect.
- The compact header switch `বাং | EN` (accessible names “বাংলা” / “English”) links to the same page in
  the other language (and keeps the open `#section` when JavaScript is available).
- "Learn about Bahon Boi" on the hub always opens the Bengali page `/bahon-boi/`.
- Hub = portfolio introduction (apps + games), not a Bahon Boi page: hero "Useful apps. Enjoyable games." /
  "কাজের অ্যাপ, আনন্দের গেম।" with *Explore apps* (`#apps`) and *Explore games* (`GAMES_URL` =
  `https://games.munna.dev`, in `src/routes.mjs`), a games gateway band, the featured Bahon Boi panel
  (screenshots live there now), developer, contact. Games content and game pages stay on games.munna.dev —
  no catalog here. Only add an app card for an app with a verified name, icon, destination and status.
- Inside Bahon Boi, every link keeps the current language. "All apps" goes to `/` (en) or `/bn/` (bn).
- Each page has `lang`, its own title/description, canonical, reciprocal `hreflang` (+ `x-default`)
  and a language-specific OG image. Earlier URLs (`/`, `/bahon-boi/…`) are unchanged.

## Project structure

```
build.mjs                 generator + checks (node build.mjs --check)
src/
  lib.mjs                 L(en, bn) bilingual strings, money/digit formatting, checks
  routes.mjs              route table and language rules
  layout.mjs              <head>, header with language switch, footer
  components.mjs          icons, example cards, breadcrumbs, link pills
  svg.mjs                 original inline SVG illustrations (theme-aware, translated labels)
  examples.mjs            accounting examples — computed and asserted at build time
  content/guide.mjs       the 11 guide topics (EN + BN)
  pages/hub.mjs  app.mjs  guide.mjs  legal.mjs   (legal.mjs also has contact + 404)
assets/                   site.css (design system), site.js (optional enhancements), hub icons, OG covers
bahon-boi/assets/         app icon sizes, favicon, logo-320.webp, OG covers (bn default, -en)
docs/FEATURE_COVERAGE.md  feature → page → app-source checklist (internal)
app-config/               hand-edited update config the apps fetch (validated by the build) — see app-config/README.md
bahon-boi/assets/screens/ genuine app screenshots (<lang>-<screen>.webp, 640×1314)
*.html, bn/, bahon-boi/   GENERATED — do not edit by hand
CNAME .nojekyll robots.txt site.webmanifest sitemap.xml (generated)
```

## Local preview (Laravel Herd)

`~/Herd` is a parked Herd path, so the site is served at **http://munna-apps.test/** with no setup.
After any change:

```sh
cd /Users/munna/Herd/munna-apps
node build.mjs --check      # Herd's Node works: ~/Library/Application Support/Herd/config/nvm/…
```

Herd quirks (production behaves correctly): unknown paths fall back to the home page instead of
`404.html`, and macOS file names are case-insensitive. For production-like behaviour use
`python3 -m http.server 8766` and open `http://localhost:8766/`.

`--check` fails on broken internal links/assets, missing `#anchors`, duplicate ids or stray HTML,
and warns about English text in Bengali pages or Bengali text in English pages.

## Editing content

- All copy goes through `L('English', 'বাংলা')`; the build stops if either side is missing.
- Feature copy must match the released app. Verify against the app's bundled guide
  (`lib/features/guide/guide_content.dart`), translations and `PROJECT_REPORT.md` §2/§8, and update
  `docs/FEATURE_COVERAGE.md`. Use the app's exact button names. Never advertise planned features.
- Accounting examples live in `src/examples.mjs`; values are computed and checked, so a wrong
  example fails the build. Label every figure as an example.
- Keep earned income, money received, dues, expenses, payments, profit, cash movement and non-cash
  adjustments separate in all copy.

### Legal pages (drafts)

Terms and Privacy show a draft banner and `TODO` markers, use `noindex`, and are left out of the
sitemap. To publish: resolve every `TODO` (`grep -rn TODO src/pages/legal.mjs`), confirm the
permission list from the release build's merged Android manifest, set the effective date, remove the
`draft-banner`, set `robots` to index in `legalPage()`, mark those routes indexable in `build.mjs`,
and rebuild.

## Images

- App icons are resized from the app's `assets/images/branding/bahon_boi_logo.png` (ImageMagick:
  `magick SRC -strip -resize 512x512 -colors 64 icon-512.png`; WebP via `cwebp -q 88 -resize 320 320`).
- Illustrations are original inline SVG in `src/svg.mjs`, coloured by CSS classes so they follow
  light/dark mode. Text labels are translated; each SVG has `<title>`/`<desc>` in the page language.
- Screenshots in `bahon-boi/assets/screens/` are genuine captures of the current app on the Pixel_9_Pro
  emulator in **normal mode (demo mode off)**, filled with fictional records by the app repo's
  development-only fixture `tool/screenshots/fixture_main.dart` (seeds through the app's own
  repositories; refuses to touch a database that already has records). Status and gesture bars are
  cropped; nothing inside the app is edited. Export: `magick X.png -crop 1280x2628+0+156 +repage
  -resize 640x Y.png && cwebp -q 80 -m 6 Y.png -o <lang>-<screen>.webp`. Shown together in the
  hero and the “Inside the app” section (no carousel); alt text and captions live in
  `SCREENS` in `src/components.mjs`.
- OG covers (1200×630) were rendered from small HTML templates with headless Chrome. The hub covers
  (`assets/og-cover.png`, `-bn`) were regenerated on 2026-11-10 with the Munna Apps mark and the apps + games
  headline.

## Header and navigation

- One row: brand · navigation · `বাং | EN` + menu button. `assets/site.js` measures whether the row
  fits (in the page's own language and fonts) and switches to the menu button before anything
  wraps; measured collapse points: hub ≈ 630–640 px (with the external *Games ↗* link), Bahon Boi ≈ 690 px (en) / 730 px (bn). Without
  JavaScript the nav wraps under the brand instead. The menu supports Escape, focus return and
  `aria-expanded`/`aria-controls`.
- The hub's *Games* nav link is external (`https://games.munna.dev`), so the scroll tracker ignores it.
  Games links appear in the hub header/footer only; Bahon Boi pages' header and footer are unchanged.
- In-page links (`#features`, `#faq`, hub sections) get `aria-current="location"` from a scroll
  tracker: the section under a line just below the sticky header is active; at the page bottom the
  last visible linked section wins; none in the hero. Links to other pages (guide, contact) get
  `aria-current="page"` only on that page. `--header-h` drives `scroll-padding-top`.

## Adding another app

1. Add routes in `src/routes.mjs` (e.g. `/<slug>/` default language, `/<slug>/en/`).
2. Create `src/pages/<slug>.mjs` (+ its own legal/contact text — never reuse another app's policy).
3. Register the pages in `build.mjs`, add assets under `/<slug>/assets/`, a card on the hub, and
   an accent class in `site.css`.
4. `node build.mjs --check`.

## Deployment (not done — needs separate authorization)

Same model as games.munna.dev: GitHub Pages → *Deploy from a branch* → `main`, `/ (root)`;
`CNAME` (`apps.munna.dev`) and `.nojekyll` are present. Cloudflare DNS: `CNAME apps →
<github-user>.github.io`, DNS-only until GitHub issues the certificate, then *Enforce HTTPS*
(and *Full (strict)* if proxied). Always run `node build.mjs --check` and commit the generated HTML
before pushing. Then submit `https://apps.munna.dev/sitemap.xml` in Search Console.
