Backup, recovery key and restore

Your records live on your phone. Backup keeps copies in a folder you choose on the phone — normal, or locked with a recovery key. Nothing is uploaded to Google Drive or the internet, so copying that folder off the phone is up to you.

When to use it

Set it up on the first day. Restore when you change phones, reinstall the app, or need to go back to an earlier copy.

Where to find it

  • Settings → Backup & Restore → Back up this phone
  • Settings → Backup & Restore → Restore existing data

What you need

  • An Android phone (folder backup is not available on iPhone).
  • A folder you choose, with free space. The app asks for access to that folder only.
  • For protected backups: a safe place, away from the phone, to write down the recovery key.

Steps

  1. Open Settings → Backup & Restore → “Back up this phone”. Step 1: choose a backup folder.
  2. Step 2: choose protection. Normal (default) needs no key: read the warning and tap “Start normal backups”. Protected: turn on “Protect backups with a recovery key”, create the key once, write it down away from the phone, tick the box and type its last 4 characters.
  3. When you finish, the first backup is saved and “Automatic daily data backup” turns on. Use “Back up now” any time.
  4. Check the status: it shows the folder, the last data backup and the last photo backup. Problems show in red with a fix.
  5. Regularly copy the whole “BahonBoi Backups” folder with the Files app to a computer, USB drive or other storage you trust.
  6. New phone: install Bahon Boi, copy the backup folder to the phone, then open Backup & Restore → “Restore existing data”. No new setup or key is needed to start.
  7. Choose the folder (or a single file) and pick a backup. A protected backup asks for its matching recovery key. Check the date, counts and photos, then confirm.
  8. After restoring, set up backups again on the new phone so “Automatic daily data backup” is on.

Result

Data backups contain all records (vehicles, owners, drivers, income, money received, expenses, documents) plus language and theme. Photos are backed up on their own schedule — weekly (default), monthly, or only when you tap “Back up now with photos” — into the folder’s “attachments” folder. The newest 30 backups are kept.

Mistakes and exceptions

  • Local backup is not cloud backup: if the phone is lost or damaged, a folder on it is lost too. Copy the folder off the phone regularly.
  • Normal backups are not encrypted: anyone who gets the files can read or restore them, including personal information.
  • If you lose both the app installation and the recovery key, protected backups cannot be opened. Nobody can recover the key for you. Never store the key in the same place as the backups.
  • Automatic timing is approximate: about once a day when Android allows; battery saver can delay it. A missed backup runs the next time you open the app.
  • Restoring a single file brings back records only; restore from the folder with “attachments” to get photos back.
  • Restore replaces all records on the phone — it does not merge. Exit demo mode before restoring.

Correct or undo

  • Before restoring, the app keeps a recovery copy of the current data. A wrong key, a damaged file or a backup from a newer app version is rejected without changing your data.
  • A failed backup never deletes earlier backups. Follow the red message: choose the folder again, free up space, or enter the recovery key.
  • “Protect backups with a recovery key” changes future backups only; earlier backups and your saved key are never changed or deleted.
